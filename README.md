# テイスティングノート (PWA) v9

ウイスキー・ジンを中心に、蒸留酒のテイスティングノートを書き溜める個人用アプリです。
Windows PC と iPad のブラウザで動き、ホーム画面/デスクトップに追加するとアプリのように使えます。オフラインでも動作します。

## ファイル構成

```
index.html              アプリ本体 (HTML/CSS/JS を1ファイルに収録)
manifest.webmanifest    PWA の設定 (名前・アイコン等)
sw.js                   Service Worker (オフライン対応)
icons/                  アイコン
```

## 公開方法 (GitHub Pages の例)

PWA (Service Worker) は HTTPS で配信されている必要があります。

1. このフォルダの中身をリポジトリ直下にアップロード (既存ファイルは上書き)
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

ノートのデータは各端末のブラウザ内にしか無いため、URLを知っている人がいても中身は見られません。

## アプリを更新して再公開するとき

`index.html` などを変更して再アップロードした後は、`sw.js` の `VERSION` を上げてください (現在 `'v9'`)。
端末側は次回の起動時に最新版を取得し、その次の起動から反映されます。

## 画面構成

- 上部タブ (大分類): ウイスキー / ジン / ラム / ブランデー / テキーラ / ウォッカ / リキュール / その他 (醸造酒・焼酎は「その他」の中分類)
  ファイルのインデックス(見出し)風のタブで、右上を斜めにカットした形に左端の色帯が付きます。選んだタブが下の一覧シートとつながって見えます。
  選択中の大分類の色で、ページ背景とシートがうっすら色付きます (詳細・編集画面ではその銘柄の大分類の色)。色の濃さは `index.html` 冒頭の `--tint-page` / `--tint-sheet` / `--tint-tab` で調整できます。
- サイドタブ (中分類): 例) ウイスキーは スコッチ / アイリッシュ / アメリカン / カナディアン / ジャパニーズ / その他。
  画面幅が狭いとき (横幅 720px 未満) は、タブの下に折り返しボタンとして表示されます。
- 一覧は1銘柄1行。項目ごとに小さなアイコンが付きます (蒸留所、地域、熟成年数、樽、度数、容量、ボトル価格、ひとこと、飲み方、フレーバータグなど)。1ショット価格は詳細画面に表示されます。
  件数の横の「アイコンの見方」で凡例を表示できます。詳細画面の各項目にも同じアイコンが付きます。
- 飲み方は おすすめ度 (◎イチオシ / ○おすすめ / △いまいち) 順に並び、◎は塗りつぶしで表示されます。
- 検索は選択中の大分類が対象です。他の大分類にもヒットがあると件数が表示され、タップで切り替わります。
- 一覧をスクロールしても、タイトル行と大分類タブは上部に残ります (iPad幅以上では検索欄・並べ替えも固定)。一定以上スクロールすると右下に「上へ戻る」ボタンが出ます。
- 一覧の表示は検索欄右のボタンで「詳細」と「コンパクト」(1銘柄1行: 銘柄名・中分類・主要項目・度数・◎の飲み方・日付) を切り替えられます。
- 詳細画面の記録は「飲み方ごと」(おすすめ度順に1行ずつ、タップで過去の記録を展開、その飲み方で記録を追加) と「日付順」を切り替えられます。
- 編集画面では、飲み方の記録が4件以上あると最後の1件以外を折りたたんで表示します。

## 酒類ごとの入力項目

| 大分類 | 主な専用項目 | 飲み方の候補に出るカクテル |
|---|---|---|
| ウイスキー | タイプ(中分類ごとに候補が変化)、地域、熟成年数、蒸留年/ボトリング年、オフィシャル/ボトラーズ、ボトラー名、樽(複数)、ピート、マッシュビル(アメリカン/カナディアンのみ)、仕様(カスクストレングス等) | なし |
| ジン | 生産国、ベーススピリッツ、キーボタニカル(複数)、仕様 | ジントニック、マティーニ、ネグローニ、ギムレット 他 |
| ラム | 生産国・地域、原料、蒸留器、熟成年数、仕様 | ダイキリ、モヒート、キューバ・リブレ、マイタイ 他 |
| ブランデー | 熟成表記(VSOP/XO等)、産地・クリュ、原料、熟成年数、ヴィンテージ、仕様 | サイドカー、ブランデー・アレキサンダー、ヴュー・カレ 他 |
| テキーラ | アガベ品種、産地、加熱方法、NOM、熟成期間、仕様(100%アガベ等) | マルガリータ、パロマ、テキーラ・サンライズ 他 |
| ウォッカ | 生産国、原料、ろ過・製法、フレーバー(フレーバードのみ) | モスコミュール、ソルティ・ドッグ、ブラッディ・メアリー 他 |
| リキュール | 主な風味・原料、ベースの酒、甘さ、生産国 | ネグローニ、スプモーニ、ゴッドファーザー 他 |
| その他 | 種別、原料、産地、熟成年数 | なし |

全酒類共通: 銘柄名、生産者、ひとことコメント (一覧に表示)、度数、容量(ml)、価格、備考、色・香り・味わい・余韻、フレーバータグ、飲み方ごとの記録 (飲み方・おすすめ度・コメント・日付・場所)、写真。

- 飲み方ごとの記録: 飲み方の候補は「飲み方」「カクテル」(ウイスキー・その他以外)「これまでの記録から」に分かれて表示され、自由入力もできます。それぞれに おすすめ度 ◎○△ を付けられます。
- 1ショットあたりの価格: 価格 ÷ 容量 × 1ショットの量 で計算します。1ショットの量 (初期値30ml) はバックアップ画面の「表示設定」で変えられます。
- 項目の定義は `index.html` 冒頭の `CATS` にまとまっているので、候補の追加・変更はそこを編集すれば反映されます。

## データの保存について (重要)

- ノートは その端末のブラウザ内 (IndexedDB) に保存され、端末間の同期はありません。
- iPad では Safari のタブと、ホーム画面に追加したアプリでデータが別々です。
- 「バックアップ」から定期的に JSON で書き出してください (30日以上バックアップが無いと一覧に案内が出ます)。
- 別の端末へは JSON を書き出し →「追加・統合して読み込む」で移せます。
- CSV は閲覧・集計用です (写真なし、飲み方ごとに1行)。

## 以前のバージョンのバックアップについて

- v9 で、v1〜v4 の頃のデータ・バックアップを変換して取り込む処理を削除しました。
- v1〜v3 で書き出した JSON は読み込めません (読み込もうとするとメッセージが出ます)。
- v4 で書き出した JSON は読み込めますが、当時の「カクテルのおすすめ」欄の内容は取り込まれません。
- v5 以降で書き出した JSON は、これまでどおり読み込めます。
