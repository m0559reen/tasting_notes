# テイスティングノート (PWA)

ウイスキー・ジンのテイスティングノートを書き溜める個人用アプリです。
Windows PC と iPad のブラウザで動き、ホーム画面/デスクトップに追加するとアプリのように使えます。オフラインでも動作します。

## ファイル構成

```
index.html              アプリ本体 (HTML/CSS/JS を1ファイルに収録)
manifest.webmanifest    PWA の設定 (名前・アイコン等)
sw.js                   Service Worker (オフライン対応)
icons/                  アイコン
```

## 公開方法 (GitHub Pages の例)

PWA (Service Worker) は **HTTPS で配信されている必要**があります。

1. GitHub で新しいリポジトリを作成 (公開範囲は Public で構いません。ノートの内容はサーバーには一切送られません)
2. このフォルダの中身をそのままリポジトリ直下にアップロード
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

パスはすべて相対指定なので、サブパス配下でもそのまま動きます。
S3 + CloudFront、Cloudflare Pages、Netlify など、静的ファイルをHTTPSで配信できる場所ならどこでも構いません。

> 公開URLを知っている人はアプリ自体は開けますが、ノートのデータは各端末のブラウザ内にしか無いため、他人に見られることはありません。

## インストール

- **iPad**: Safari でURLを開く → 共有ボタン → 「ホーム画面に追加」
- **Windows**: Edge / Chrome で開き、アドレスバー右端のインストールアイコンから追加 (アプリ内「バックアップ」画面にもボタンがあります)

## データの保存について (重要)

- ノートは **その端末のブラウザ内 (IndexedDB)** に保存され、端末間の同期はありません。
- iPad では **Safari のタブと、ホーム画面に追加したアプリでデータが別々**です。ホーム画面に追加してから記録を始めてください。
- 端末の故障・ブラウザのデータ消去に備え、アプリ右上の「バックアップ」から **定期的にJSONで書き出して**保管してください (30日以上バックアップが無いと一覧画面に案内が出ます)。
- 端末の引っ越しや、PCとiPadでデータを合わせたいときは、JSONを書き出して別端末で「追加・統合して読み込む」を使います。同じノートは新しい方が残ります。
- CSV書き出しはExcel等での閲覧・集計用です (写真は含まれません)。復元にはJSONを使ってください。

## アプリを更新して再公開するとき

`index.html` などを変更して再アップロードした後は、`sw.js` の `VERSION` (`'v1'` → `'v2'`) を上げてください。
端末側は次回の起動時に最新版を取得し、その次の起動から反映されます。保存済みのノートには影響しません。

## 機能

- 記録項目: 種類 (ウイスキー/ジン/その他)、銘柄名、蒸留所・ブランド、タイプ、産地、度数、熟成年数、価格、色・香り・味わい・余韻・総合コメント、フレーバータグ、日付、場所・店名、飲み方、写真
- フレーバータグ: プリセット + 自分で追加 (ジンを選ぶとボタニカル系のタグが出ます)
- 一覧: 検索 (ひらがな/カタカナ・全角/半角の違いを吸収)、種類での絞り込み、タグ絞り込み (AND)、並べ替え
- 同じ銘柄の過去ノート表示、「同じ銘柄で新しいノートを書く」
- 入力中の下書き自動保存 (画面を閉じても復元)
- バックアップ: JSON / CSV 書き出し、JSON 読み込み (統合/置き換え)
- ダークモード (端末の設定に自動追従)
